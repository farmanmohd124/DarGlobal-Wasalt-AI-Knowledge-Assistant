# DarGlobal & Wasalt Chatbot
RAG chatbot over scraped public data → OpenRouter free LLM with automatic model fallback.

## Retrieval pipeline (hybrid + cross-encoder)
1. **BM25** (sparse keyword) top-10  2. **Dense** vector search, `BAAI/bge-small-en-v1.5` (fastembed/ONNX) top-10
3. **Reciprocal Rank Fusion** merges both rankings  4. **Cross-encoder rerank**, `Xenova/ms-marco-MiniLM-L-6-v2`, keeps the best 4 for the LLM.
Models are downloaded at Docker build time. If a model is unavailable the app degrades gracefully (hybrid → BM25 only). `DISABLE_NEURAL=1` forces BM25-only; `DISABLE_RERANK=1` skips only cross-encoder reranking while retaining dense search. The chat UI shows answers and source citations; detailed pipeline timings remain in LangSmith. `/health` reports which retrieval stages are active. FastAPI + single-page UI, Docker-ready.

## LangSmith tracing
Tracing is opt-in. Add `LANGSMITH_TRACING=true`, your `LANGSMITH_API_KEY`, and optionally `LANGSMITH_PROJECT=darglobal-wasalt-chatbot` to `.env`, then rebuild and restart the container. `GET /health` reports whether tracing is configured. Chat traces include BM25, query embedding, dense similarity, rank fusion, reranking, context assembly, and each OpenRouter model attempt. Startup traces include loading documents, loading retrieval models, and building document embeddings. Running `python scraper/scrape.py` records a parent ingestion trace with child spans for fetching, extracting, chunking, crawl delay, and writing pages.

Trace inputs omit raw questions, conversation history, API keys, and document text; they retain stage timings, counts, model names, response status, and selected document titles. In LangSmith, select the configured project to compare each component's duration. Ingestion spans appear when the scraper is run; they are not generated by normal chat requests.

## Run locally
    docker build -t re-chatbot . && docker run -p 7860:7860 --env-file .env re-chatbot
    open http://localhost:7860

## Deploy on Vercel
Vercel detects the FastAPI application at `app/main.py` and deploys it as a Python Function. Set `OPENROUTER_API_KEY` in the Vercel project environment variables; add `LANGSMITH_TRACING`, `LANGSMITH_API_KEY`, and `LANGSMITH_PROJECT` there only if tracing is needed. `MODEL_CACHE` defaults to `/tmp/models` for the function's writable temporary storage. The first cold start may take longer while the embedding model downloads and initializes.

## Deploy (free) – Render
1. Push this folder to a GitHub repo. 2. Render → New → Blueprint → select repo (uses render.yaml). 3. Set env var OPENROUTER_API_KEY (free key from openrouter.ai/keys). 4. Your URL: https://darglobal-wasalt-chatbot.onrender.com
(Hugging Face Spaces also works: create a Docker Space, upload these files, add OPENROUTER_API_KEY as a secret; port 7860 is already the default.)

## Refresh data
    pip install -r requirements.txt && python scraper/scrape.py   # writes data/scraped.json, merged at startup
Endpoints: GET / (UI), POST /api/chat, GET /health
